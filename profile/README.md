# BroideryFab

**Free, fast tools for machine embroidery files — in your browser, no account required.**

Open, inspect, convert and check embroidery designs (DST, PES, JEF and more)
without installing software. 🧵

🌐 [broideryfab.com](https://broideryfab.com)

## Open source

| Repository | What it is | Status |
|---|---|---|
| [embroidery-ksy](https://github.com/broideryfab/embroidery-ksy) | [Kaitai Struct](https://kaitai.io) specifications for machine embroidery file formats | 🚧 Work in progress (pre-1.0) |

Machine embroidery formats are mostly undocumented. We publish what we learn
as open, machine-readable specs so anyone can build on them.
