# broideryfab/.github

Organization-wide GitHub configuration for [BroideryFab](https://broideryfab.com).

| Path | Purpose |
|---|---|
| `profile/README.md` | Public organization profile shown at [github.com/broideryfab](https://github.com/broideryfab) |
| `CONTRIBUTING.md` | Default contributing guide for public repositories |
| `SECURITY.md` | Default security policy for public repositories |
| `.github/ISSUE_TEMPLATE/` | Default issue templates for public repositories |

A repository's own file of the same name overrides these defaults.
